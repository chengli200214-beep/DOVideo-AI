# 项目库与参考素材库

在 `/?storyboard` 登录后，左侧“项目库”可以搜索、翻页、归档和恢复自己的创作项目。“参考素材库与清理”集中展示当前账号上传的参考图片，可预览、再次使用或删除未用图片。以上管理操作不会提交付费模型任务。

## 查找和整理项目

在项目库输入项目名称、产品信息或完整项目 ID，点击“搜索”。关键词匹配创建项目时保存的创作需求，不搜索生成视频内容；英文匹配不区分大小写，`%`、`_`、`!` 按普通字符处理。列表默认每页 20 项，通过“加载更多”继续访问更早的项目，不受旧接口最近 50 项的展示范围限制。

列表按最后更新时间倒序排列，同一时间按项目 ID 排序。搜索条件、归档筛选或账号变化时会重新载入第一页。项目在翻页期间被编辑或归档可能改变排序；需要查看最新状态时点击“刷新”。

完成一个项目后，可以点击“归档”。归档保留原项目 ID、全部分镜修订、镜头生成记录、成片和产物，不释放已经使用的模型额度或删除引用素材。勾选“查看已归档项目”后可继续查看原记录，点击“恢复项目”即可重新编辑和生成。

有进行中或提交结果未知的镜头、分镜模型任务，以及正在排队或合成的成片时，服务会拒绝归档。归档项目保持只读：编辑、确认、额度配置、新生成、成片合成、任务恢复和新增质量评分都需先恢复项目。页面存在未保存的分镜修改时，先保存或明确放弃这些修改，再切换或归档项目。

## 使用参考素材

展开“参考素材库与清理”，可以查看图片尺寸、大小和使用状态，点击“预览”读取短时效私有地址。点击“用作参考图”会将该图片填入新建项目的参考图字段，并加入镜头参考图可选项；编辑现有镜头时，在镜头表单中选择对应素材，再保存并确认分镜。

上传仍使用 PNG/JPEG，最大 5 MiB、最长边不超过 4096 像素。图片格式和实际内容会被检查；具体视频模型可能另有最小尺寸要求。当前账号重复上传相同内容会复用已有素材记录，其他账号的图片不会出现在此素材库。

“已被项目或任务引用”的图片不能删除。保护范围包含项目原始需求、所有历史分镜和生成任务输入；即使新分镜已换图、项目已归档或旧生成任务失败，历史引用仍然保留。升级前没有规范化引用表记录的旧 JSON 数据也会检查，发现对应素材 ID 就保守地保留图片。

页面还会保护当前创作需求、正在编辑的镜头，以及当前账号在本浏览器保存的其他项目草稿所用图片；删除前再次核对。浏览器存储无法读取时暂停删除，避免误判。其他设备或尚未持久化的草稿仍不属于服务端引用；跨设备整理素材前应先把分镜保存到服务端。

## 删除和清理状态

对“未引用”的图片点击“删除未用素材”并确认后，素材立即从可选列表中移除，同时创建持久化清理任务。**返回删除成功表示已受理清理，不表示对象存储中的文件已经删除。** 此操作没有恢复入口；需要再次使用时重新上传图片。

| 状态 | 含义和操作 |
| --- | --- |
| `PENDING` | 等待后台清理，或存储暂时失败后等待下一次尝试 |
| `DELETING` | 正在删除对象存储文件 |
| `SUCCEEDED` | 对象删除完成；重复删除请求返回同一清理记录 |
| `FAILED` | 尝试达到上限后仍失败；修复存储连接或权限后点击“重试清理” |

后台默认每 30 秒检查一次待处理任务，每次最多取 10 条。存储失败按退避时间重试，达到 5 次尝试后仍失败则停止自动重试；应用重启后继续处理持久化队列。页面“刷新”会更新清理状态，最近 20 条清理记录可通过接口查询，页面隐藏已成功的记录。重试清理只处理原图片对象，不重新调用生成模型。

应用不会按素材年龄批量删除文件，也不会通过项目归档删除视频。正常删除仅限用户明确选中的未引用图片；并发重复上传产生的多余对象会进入同一清理队列。

## API

所有接口要求当前用户登录，只访问该用户的数据。成功返回统一结构 `{ "code": 0, "message": "success", "data": ... }`。

| 方法 | 路径 | 参数和返回 |
| --- | --- | --- |
| GET | `/generation/projects/page` | `q`、`archived=false`、`limit=20`、可选 `beforeUpdatedAt` 和 `beforeId`；返回 `{items,nextCursor}` |
| POST | `/generation/projects/{id}/archive` | JSON `{ "archived": true }` 归档；`false` 恢复；返回包含 `archived` 的项目详情 |
| GET | `/generation/projects/{id}` | 查看当前分镜与项目状态；已归档项目仍可读取 |
| GET | `/generation/projects/{id}/revisions` | 查看保留的分镜、规划尝试和确认历史 |
| GET | `/generation/assets` | `limit=20`、可选 `beforeCreatedAt` 和 `beforeId`；返回 `{items:[{asset,referenced}],nextCursor}` |
| POST | `/generation/assets` | multipart 字段 `file` 上传 PNG/JPEG；返回素材元数据 |
| GET | `/generation/assets/{id}/preview` | 返回所属用户素材的短时效预签名预览地址 |
| DELETE | `/generation/assets/{id}` | 删除未引用素材并返回清理记录；相同用户重复请求复用该记录 |
| GET | `/generation/assets/cleanup` | 返回当前用户最近 20 条清理记录 |
| POST | `/generation/assets/cleanup/{id}/retry` | 仅重试 `FAILED` 清理任务，返回新的等待状态 |

两种分页接口的 `limit` 均允许 1–50。首次请求不传游标；后续请求沿用搜索和筛选条件，将项目 `nextCursor.updatedAt` 作为 `beforeUpdatedAt`，或素材 `nextCursor.createdAt` 作为 `beforeCreatedAt`，并同时传递 `nextCursor.id` 为 `beforeId`。`nextCursor=null` 表示没有下一页；游标中的时间和 ID 必须成对传入。项目搜索词最长 120 字。

例如，查询包含“水杯”的活动项目使用 `GET /generation/projects/page?q=水杯&archived=false&limit=20`；客户端需正常 URL 编码查询参数。旧的 `GET /generation/projects` 继续提供最近 50 个未归档项目，完整项目库使用 `/page`。

## 数据保护与验收

V11 迁移增加项目归档字段、素材引用表及对象清理队列。新增素材引用与素材删除都会锁定同一素材行，并使用外键约束：引用先提交时删除会被拒绝；删除先提交时新引用会失败并回滚，不留下指向已删图片的任务。

每次需要新建素材时，上传对象采用独立 UUID 对象名。即使图片内容相同，删除后重新上传的对象也拥有新地址，延迟到达的旧清理操作不能误删新上传文件。清理工作者领取任务时取得 UUID 租约；写回结果必须匹配当前租约，因此旧工作者迟到的成功或失败结果不能覆盖新一轮清理，包括人工重试导致尝试次数重置的情况。

离线回归覆盖 55 个项目的游标分页、字面通配符搜索、跨账号隔离、归档及恢复、旧 JSON 引用保护、存储失败重试、同内容重传对象隔离、引用与删除的两种并发顺序，以及清理租约失效后的迟到结果。测试使用 H2 和存储替身，没有真实模型调用或真实对象删除。MinIO 已有桶策略与启动检查见 [存储隐私说明](storage-privacy.md)。
