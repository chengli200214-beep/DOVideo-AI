# 脚本与可编辑分镜：第二阶段

本阶段新增「创作需求 → 产品介绍模板草稿 → 镜头编辑 → 保存修订 → 人工确认」闭环。使用本地 `product-template-v1`，不调用 LLM、图片或视频模型，也不解释参考图片内容。图片用于后续图生视频的素材引用，需要用户检查与脚本是否一致。

## 使用入口

启动现有后端和 Vue 前端后，登录并选择「脚本与分镜」，或访问 `/?storyboard`。

1. 填写项目名称、产品名称、目标、1–8 条卖点、风格、期望总时长、镜头数和画幅；可上传私有 PNG/JPEG 产品图片。
2. 创建模板分镜。每个镜头包含稳定 ID、连续序号、主体、动作、场景、运镜、参考素材 ID、期望时长、画幅、字幕、口播、提示词、提示词版本和可选生成参数。
3. 编辑脚本和镜头，调整顺序、增加／删除镜头。画面字段变化后可点「根据分镜更新提示词」，也可直接修改提示词；该操作仅拼接文本，不调用模型。
4. 保存新修订，逐镜头检查后点击「确认当前分镜」。编辑已确认版本后会回到待确认状态。历史版本可载入编辑区，再保存为新版本。

第三阶段已按确认版本接入镜头级生成与局部重生成，见 [镜头生成说明](shot-generation.md)。确认后需在「镜头生成」区域配置额度并明确提交，确认本身不会启动模型调用。期望时长是剪辑规划，不代表供应商支持该时长，更不会自动加入模型请求参数。

## 数据与校验

Flyway `V6__creative_storyboards.sql` 新增创作项目、不可变分镜修订、规划尝试和确认历史四张表。项目保存原始需求；幂等摘要使用归一化需求，原始需求不会被后续编辑覆盖。初稿标记 TEMPLATE，用户稿标记 USER；每次编辑保留父修订号。提示词版本由服务端按稳定镜头 ID 和内容变化推导，忽略客户端计数。

结构限制：2–8 个镜头，每镜头期望时长 2–15 秒，总时长必须等于需求；画幅为 16:9、9:16、1:1，镜头画幅需与项目一致；镜头 ID 不重复、序号连续、必填画面字段与提示词存在且长度受限。所有参考素材都必须属于当前用户。

规划最多尝试两次，第二次收到上次的校验错误。仍不合法或规划异常时保存尝试记录并进入 NEEDS_EDIT，提供可手动修复的空分镜；不能直接确认。生产配置目前只包含本地模板规划器，付费规划器尚未接入。

## API

全部接口位于已受鉴权保护的 `/generation/**`，沿用 `Authorization: Bearer <token>` 与统一 Result 响应。

| 接口 | 用途 |
| --- | --- |
| `POST /generation/projects` | 创建项目；必须提供 Idempotency-Key，首次 201，同需求重放 200，变更需求复用 key 返回 409 |
| `GET /generation/projects` | 本人最近 50 个项目摘要 |
| `GET /generation/projects/{id}` | 原始需求、当前状态与当前修订 |
| `GET /generation/projects/{id}/revisions` | 不可变修订、规划尝试、确认历史 |
| `POST /generation/projects/{id}/revisions` | 提交 `{expectedRevision, draft}`，保存新修订 |
| `POST /generation/projects/{id}/confirm` | 提交 `{expectedRevision}`，仅确认当前且通过校验的修订 |

创建请求示例：

```json
{
  "title": "运动鞋产品介绍",
  "goal": "突出轻便与透气，制作产品展示短视频",
  "productName": "白色运动鞋",
  "sellingPoints": ["轻便", "透气", "易搭配"],
  "style": "自然光，简洁产品展示",
  "desiredDurationSeconds": 15,
  "frameRatio": "9:16",
  "referenceAssetId": null,
  "shotCount": 3
}
```

用户不拥有的项目、修订和确认接口统一返回 404。保存使用版本号条件更新；两个不同编辑稿争用同一父版本时，只接受一个，另一个返回 409。丢失保存响应后，以相同父版本和相同规范化内容重放会复用已保存的新修订。确认记录同一项目／修订只记一次；对旧修订的确认返回 409。状态、修订与确认历史通过短事务一起提交，不跨网络调用持有事务。

前端创建 key 按账号保存摘要与 key，网络错误保留输入与 key。保存冲突保留未提交编辑，用户可查看并重新载入已保存版本；重新载入会放弃当前未保存的修改。切换账号、项目或退出页面后，旧请求不能覆盖新页面。正在载入项目时编辑区禁用，避免输入被后到的读取结果覆盖。
